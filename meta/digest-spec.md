# 日报规范

## 公开安全（必读）

本仓与 Pages **公开可读**。写入 `digests/`、`meta/`、README 时遵守：

**禁止写入公开文件**
- 密钥、token、cookie、`.env`、私钥、API 额度 / credits / 账单
- 未公开的实验数字、内部评审意见、未发表手稿全文、私人通信
- 个人敏感信息（手机、私人邮箱、住址、证件号等）
- 平台内部工具名、agent/自动化内部 ID、本机绝对路径（接管文档用角色与意图描述即可）
- 检索过程备注（「非本窗口」、`max_results`、tool 名等）

**允许写入**
- 已公开学术身份与实验室归属（以 blog / academic / 个人主页为准）
- 公开论文、开源仓库、会议录用等公开事实
- 研究方向与课题焦点的**公开表述**（如 Real→Sim→Real、可重光照 3DGS），勿写未公开的具体实验配置或未披露结果

拿不准：默认不写进公开仓；可只在与用户的私聊里说明。

## 成稿形态（完整版）
- 今日速览 / 总体总结：有判断、点名必读；文笔自然，像研究笔记
- 主题分块用自然语言标题（如「逆渲染与材质」「正向渲染效率」「可编辑动态资产与绑定」「具身数据增强与回环」）
- 正文**不要**标注 `[A]` / `[B]` / `[C]`（内部仍可按拆分绑定 / 正向效率 / 逆渲染加权）

## 论文标题栏（目录可见）

三级标题格式（会进入站点 TOC）：

```text
### 短名 · Venue或arXiv · YYYY-MM-DD
```

示例：
- `### LightBridge · arXiv · 2026-09-02`
- `### UniMate · SIGGRAPH Asia 2026 · 2026-09-04`
- `### TileGS · Pacific Graphics 2026 / CGF · 2026-09-03`

规则：
- 已接收会议/期刊：写正式 venue 名 + arXiv 挂出日（或正式发表日，若已知且更准）
- 仅预印本：`arXiv · 首次挂出日`
- 标题上方保留稳定锚点：`<a id="slug"></a>`
- 正文仍保留完整 **发表时间** / **投稿信息** 字段，供细读；TOC 靠标题栏一眼看到会议与时间
- 圈内动态等非论文小节（媒体 / X / Ke-Sen 等）不要硬套「· Venue · 日期」

## 每篇必含字段
1. 一句话判断要点（标题下首段）
2. Title（英文全名）
3. 作者（英文 / 拼音，不译成中文姓名）
4. 单位（仅确定国内机构用中文；不确定保留原文）
5. 投稿信息（已接收 / 推测+依据 / 未标明；禁止把推测写成已中）
6. 发表时间（预印本：arXiv 首次挂出日；已发表：会议/期刊时间）
7. arXiv abs / PDF（或其它稳定入口）
8. 摘要中译
9. **方法概要**（尽量基于全文 / HTML，勿只靠摘要臆造模块）
10. **值得关注**（相对公开研究方向的对照阅读建议；勿泄露未公开实验）
11. 相关链接（主页 / 代码 / 视频；找不到如实写）
12. 配图嵌入正文（pipeline / teaser；必读至少 1 张）

## 去重
- 清单：`meta/seen-papers.json`（与 Bot 侧 ledger 同步）
- 默认不重复收录
- 例外须注明「为何重提」：新版本、新录用、重要开源、圈内新观点/新影响
- 「新兴趣相关」可重复、可不限近日；须标明为何与兴趣相关

## 信息源
- arXiv（cs.GR + 关键词漏斗）与 Ke-Sen
- GitHub：`rubatotree/blog`、`rubatotree/academic`（以 **commits** 校准兴趣，不只看 Pages）
- 机器之心 / 量子位 / 新智元；PaperWeekly 类
- 公开搜索（Scholar / 网页）
- X：关键词检索（估成本；**过程与额度不写进正文或公开 meta**）

## 节奏
- 每天 06:00（Asia/Hong_Kong）生成并推送本仓 / Pages
- 自 2026-09-08 起须稳定执行

## 版式顺序
1. 标题（`# YYYY-MM-DD 科研日报` 或等价）
2. **今日速览**（置顶；论文名用 markdown 链到锚点）
3. 各主题正文
4. 圈内动态 / 新兴趣相关（如有）
5. 文末 **覆盖说明**（覆盖窗口、数据完备性等元信息放这里）
6. 不要写「读者：…」；不要写「策展版 vN 生成：…」类水印页脚

## 日期约定
- **日报日期**（文件名 `digests/YYYY-MM-DD.md`、站点选日）= **发布日**（通常为早上 6:00 HKT）
- **内容覆盖** = **前一自然日**的新内容（例如 9 月 7 日日报写 9 月 6 日新稿）
- 文末「覆盖说明」同时写明日报日期与内容覆盖日；周末等无独立 arXiv 公告时，可纳入相邻公告日积压，但发布日仍用当日
- `digests/index.json` 条目建议含 `content_day`

## 禁止写入正文的过程信息
- 「非本窗口」等内部策展切口
- X/API 余额、tool 名、`max_results`、credits 等检索过程备注
- 任何密钥或可识别私密路径
